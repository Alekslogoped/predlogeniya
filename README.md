# Крути и говори!

Статическая браузерная игра для дошкольников: ребёнок составляет предложение по картинкам, взрослый подтверждает устный ответ. Два уровня по пять раундов. Микрофон и сеть игре не нужны.

## Запуск

Откройте `index.html` в современном браузере или запустите из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Установка зависимостей и сборка не требуются. HTML подключает обычные `defer`-скрипты; данные не загружаются через fetch. Все ресурсы локальные и используют относительные пути.

## Игра

Познакомьте ребёнка с героями и знаками действий. Нажмите «Крутить!», дождитесь остановки и предложите составить предложение. «Предложение готово!» нажимает взрослый. Расширенные осмысленные ответы тоже допустимы. Следующий раунд запускается вручную.

Настройки взрослого открываются кнопкой ⚙. Там доступны знакомство с пятью действиями, прямой запуск второго уровня и включение текстового примера. Пример по умолчанию скрыт. Подсказка, увеличение карточки и пример не засчитывают ответ. В браузере сохраняются только две настройки: звук и доступность примера.

## Структура и изменение данных

- `data.js` — герои, действия, объекты, настроения и пять допустимых пар.
- `game.js` — состояния, Fisher–Yates, анимация, подтверждение и интерфейс.
- `styles.css` — оформление, адаптация и reduced motion.
- `assets/` — 20 прозрачных карточек 1024×1024 и два фона 1920×1080.
- `ASSETS.md` — происхождение и перечень изображений.

При замене иллюстрации сохраняйте имя файла и прозрачность. Для изменения лексики обновляйте формы слов в `data.js`. Действия и объекты выбираются через `pairs`, а не независимо. Текущий алгоритм предполагает пять элементов каждой категории и пять раундов. Для иного количества нужно отдельно изменить логику прогресса.

При недоступном файле запуск блокируется, а настройки взрослого показывают конкретный путь. Не заменяйте отсутствующие изображения emoji.

## Genially

После публикации вставьте HTML:

```html
<iframe src="https://alekslogoped.github.io/predlogeniya/"
  width="100%" height="720" style="border:0"
  title="Крути и говори" allow="fullscreen"></iframe>
```

На небольшом вертикальном экране дайте iframe достаточную высоту (например, 820 px). Игра использует реальные размеры iframe, не обращается к родительскому документу и работает без разрешения fullscreen. Полноэкранная кнопка появляется только при доступном API.

## Проверки

Проверено в Chromium: последовательное прохождение уровней, прямой второй уровень, уникальность всех очередей, допустимые пары, согласование рода, двойное подтверждение, отмена таймеров при выходе, загрузка ресурсов, адаптация 1600×900, 390×844, 844×390 и 768×1024. Анимации учитывают `prefers-reduced-motion`. Проверены также обычная анимация, отмена её таймеров при выходе, увеличение/Escape, iframe и работа при заблокированном localStorage. Открытие `file://` в браузере облачной среды заблокировано политикой; используйте HTTP.

Регрессионные проверки находятся в `tests/game.cjs` и `tests/browser.cjs`. Для них требуется Node.js с Playwright и Chromium в `/usr/bin/chromium`; установите Playwright отдельно от приложения (например, в `/tmp/kg-tests`), запустите HTTP-сервер на порту 8000, затем выполните оба файла через Node. В текущей облачной среде Playwright и Chromium уже доступны.

Перед занятиями взрослому рекомендуется оценить узнаваемость пяти пиктограмм на реальном устройстве. Автоматические проверки не подтверждают их понятность конкретному ребёнку.
