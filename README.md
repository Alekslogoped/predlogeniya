# Крути и говори!

Статическая браузерная игра для дошкольников: ребёнок составляет предложение по картинкам, взрослый подтверждает устный ответ. Два уровня по пять раундов. Микрофон и сеть игре не нужны.

## Запуск

Откройте `index.html` в современном браузере или запустите из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Установка зависимостей и сборка не требуются. HTML подключает обычные `defer`-скрипты; данные не загружаются через fetch. Все ресурсы локальные и используют относительные пути.

## Новое оформление и запуск

Игра сразу показывает рабочий экран первого уровня без обложки и кнопки «Играть». До первого вращения в окнах нейтральные знаки категорий. После предзагрузки полного набора становится доступна кнопка «Крутить!». «Герои» и «Как играть» открывают необязательные окна, не сбрасывая раунд. «Начать заново» после подтверждения сбрасывает всю сессию на первый уровень.

Корпус расположен в общей системе координат с карточками; в вертикальном режиме применяется компактный CSS-корпус без растягивания PNG. Отдельный рычаг внутри настоящей кнопки опускается на 55° за 200 мс, задерживается на 100 мс и возвращается за 280 мс. Запуск через основную кнопку вызывает такое же движение. При reduced motion используется мягкая подсветка. Перезапуск отменяет таймеры и анимации.

## Статус материалов

Набор полный: 23 PNG. Двадцать карточек и игровой фон предоставлены пользователем и сохранены без изменения байтов. Лошадь взята из отдельного архива «Милая мультяшная лошадка.png.zip». Корпус обновлён генератором изображений: ручка удалена, белое поле очищено; отдельный рычаг также сгенерирован. Пользовательская лошадь стоит на четырёх ногах без комбинезона — используется выбранная пользователем иллюстрация.

При недоступном файле запуск заблокирован, а настройки взрослого показывают конкретный путь. Добавьте PNG под указанными именами и обновите страницу; код менять не потребуется. Не заменяйте эти ресурсы emoji.

## Структура и изменение данных

- `data.js` — герои, действия, объекты, настроения, связанные пары и пути ресурсов.
- `game.js` — состояния, Fisher–Yates, движение рычага, вращение и подтверждение.
- `styles.css` — расположение внутри корпуса, адаптация и reduced motion.
- `assets/` — предоставленные пользователем изображения.
- `ASSETS.md` — происхождение, перечень и статус каждого изображения.

Настройки взрослого позволяют сразу открыть второй уровень и включить текстовый пример (по умолчанию скрыт). Подсказки и увеличение карточек не засчитывают ответ. Сохраняются только звук и доступность примера.

## Genially

После публикации вставьте HTML:

```html
<iframe src="https://alekslogoped.github.io/predlogeniya/"
  width="100%" height="720" style="border:0"
  title="Крути и говори" allow="fullscreen"></iframe>
```

На небольшом вертикальном экране дайте iframe достаточную высоту (например, 820 px). Игра использует реальные размеры iframe, не обращается к родительскому документу и работает без разрешения fullscreen. Полноэкранная кнопка появляется только при доступном API.

## Проверки

Тесты требуют Node.js, Playwright и Chromium в `/usr/bin/chromium`. Эти инструменты доступны в текущей облачной среде. Запустите HTTP-сервер на порту 8010, затем:

```sh
node tests/game.cjs
node tests/browser.cjs
```

При другом порте задайте `GAME_URL`. `game.cjs` проверяет реальную предзагрузку и конкретные сообщения об отсутствующих файлах. `browser.cjs` требует полный набор и проверяет оба уровня, уникальность очередей, допустимые пары, двойные клики, прямой второй уровень, правила, галерею, перезапуск, анимацию рычага и четыре размера экрана.

Для изолированной проверки механики можно использовать `KG_TEST_FIXTURES=1 node tests/browser.cjs`: отсутствующий PNG заменяется только в памяти тестового браузера. Этот режим не нужен для полного набора: стандартные проверки выполняются с настоящими картинками. Подстановки не записываются в игру.
